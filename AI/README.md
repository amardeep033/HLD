## Recommended Reading Order

Start with fundamentals, then LLMs, prompts, RAG, embeddings, and vector databases. After that, study agents, MCP, tool calling, serving, training vs inference, fine-tuning, and security. Finish with system design, discussion questions, the cheat sheet, and glossary.

```text
Fundamentals -> LLMs -> Prompts/Tokens -> RAG -> Embeddings -> Vector DBs
             -> Agents -> MCP/Tools -> Serving -> Security -> System Design
```

## discussion Strategy

- Explain AI systems like distributed backend systems with probabilistic components.
- Always mention latency, cost, quality, safety, monitoring, and failure modes.
- Prefer simple language: retrieval, ranking, generation, evaluation, fallback.
- Separate model behavior from platform behavior.
- Use examples: support bot, coding assistant, internal knowledge search.

> Tip: In discussions, a clear architecture and tradeoff discussion beats model-name trivia.
