## Comparison Table (if applicable)

| Term | Short definition |
|---|---|
| Agent | LLM system that can choose actions and use tools |
| Agentic AI | Autonomous workflow style using model-driven decisions |
| AI | Software that performs human-like judgment tasks |
| AI Gateway | Shared layer for model auth, routing, quotas, and logs |
| AI Observability | Metrics, logs, traces, prompts, outputs, and quality signals |
| Chunking | Splitting documents into retrievable sections |
| Context Window | Maximum tokens a model can process in one request |
| Deep Learning | Neural-network-based machine learning |
| Embedding | Vector representation of meaning |
| Evals | Tests or measurements for model quality and safety |
| Fine-tuning | Additional training to adapt model behavior |
| Foundation Model | Large general-purpose model used across tasks |
| Generative AI | AI that creates new content |
| Guardrails | Controls around input, output, and actions |
| Hallucination | Plausible but unsupported or false model output |
| Inference | Running a trained model to produce output |
| LLM | Large language model that predicts/generates tokens |
| MCP | Protocol for exposing tools and resources to AI clients |
| Model Serving | Operating models behind APIs |
| Prompt | Instructions and context sent to a model |
| Prompt Injection | Malicious or conflicting text that tries to override instructions |
| Quantization | Reducing model numeric precision for efficiency |
| RAG | Retrieval-augmented generation using external context |
| Semantic Search | Search by meaning |
| System Prompt | High-priority model instruction |
| Temperature | Controls output randomness |
| Token | Unit of text processed by a model |
| Tool Calling | Structured model-requested function invocation |
| Training | Learning model parameters from data |
| Vector Database | Database for similarity search over embeddings |

## Key Takeaways

Good discussion answers define the term, place it in architecture, and mention tradeoffs or risks.
