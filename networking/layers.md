| Component                          | Hardware?                        | Software?                  | Famous Examples                            | Physical Place                                | Main OSI Layer(s)                                   |
| ---------------------------------- | -------------------------------- | -------------------------- | ------------------------------------------ | --------------------------------------------- | --------------------------------------------------- |
| Browser/App                        | ❌                                | ✅                          | Google Chrome, Mozilla Firefox             | **Your laptop**                               | Layer 7 — Application                               |
| Laptop OS / Networking Stack       | ❌                                | ✅                          | Linux, Windows                             | **Your laptop**                               | Layer 3–4 (IP/TCP/UDP), partly Layer 2              |
| Wi-Fi NIC                          | ✅                                | ✅ drivers/firmware         | Intel Wi-Fi card, Realtek NIC              | **Inside your laptop**                        | Layer 1–2 (Physical + Data Link)                    |
| Office Access Point                | ✅                                | ✅ firmware                 | Cisco APs, Ubiquiti UniFi                  | **Office ceiling/walls**                      | Layer 1–2                                           |
| LAN Switch                         | ✅                                | Sometimes managed software | Cisco switches, Juniper Networks           | **Office server/network room**                | Mostly Layer 2                                      |
| Gateway Router                     | ✅                                | ✅ routing OS/software      | Cisco routers, MikroTik                    | **Office edge/network room**                  | Layer 3 — Network                                   |
| Firewall                           | Often dedicated appliance        | ✅ filtering/security logic | Palo Alto Networks, Fortinet FortiGate     | **Company network edge / datacenter**         | Mostly Layer 3–4, modern firewalls also Layer 7     |
| VPN Client                         | ❌                                | ✅                          | Fortinet FortiClient, Cisco AnyConnect     | **Your laptop**                               | Layer 3–4 (tunneling/encryption), sometimes Layer 7 |
| VPN Gateway / VPN Server           | Sometimes appliance              | ✅ VPN server software      | FortiGate VPN, OpenVPN server              | **Company datacenter / cloud**                | Layer 3–4                                           |
| DNS Resolver / DNS Server          | Usually server hardware/cloud VM | ✅                          | Google DNS, Cloudflare DNS                 | **ISP/cloud/company infra**                   | Layer 7 — Application                               |
| Forward Proxy / Secure Web Gateway | Sometimes appliance              | ✅                          | Zscaler, Squid                             | **Company cloud / security provider network** | Mostly Layer 7                                      |
| Reverse Proxy                      | Usually software                 | ✅                          | Nginx, Envoy                               | **Near backend servers/cloud infra**          | Layer 7                                             |
| Load Balancer                      | Appliance or software            | ✅                          | F5, Amazon ALB/NLB                         | **Cloud edge/datacenter**                     | Layer 4 or Layer 7                                  |
| Company Dev App                    | Usually cloud VMs/containers     | ✅                          | Internal Rust backend, Kubernetes services | **Company AWS/Azure/GCP VPC**                 | Layer 7                                             |
| Database Server                    | Usually server hardware/cloud VM | ✅                          | PostgreSQL, ClickHouse                     | **Cloud/datacenter/private subnet**           | Layer 7                                             |
| Internet Backbone                  | Massive hardware                 | Massive software           | ISPs, undersea cables, BGP routers         | **Outside everywhere globally**               | Mostly Layer 1–3                                    |
